# 合作集团线上结算系统 · 原型

依据 PRD V1.1 及 **2026-09-10 业务评审纪要** 调整后的独立原型。

## 核心规则（评审后）

- **分账推送**：分佣/分成、一次性、周期性各自独立账单，不合账（账期与推送节奏不同）
- **推送节奏**：周期性约每月 6 号；分佣约每月 10 号（可配置）
- **工作台**：按账期筛选合计查看；展示应收 / 应付 / 实收 / 实付 / 发票；**不做轧差**
- **收付款**：仅丽呈财务登记操作；合作集团侧只读查看
- **发票**：账单上申请开票（跳转现有开票流程）；应付丽呈的票可上传，OCR + 人工校验

## 本地预览
